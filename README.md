# Prototipo de Aplicación Web para Gestión de Citas

## 📌 Descripción del proyecto

Este proyecto es un **prototipo de aplicación web** diseñado para la **gestión de citas** de manera simple, rápida y eficiente. Está pensado para profesionales, clínicas, consultorios o pequeños negocios que necesitan organizar sus citas con clientes o pacientes.

El prototipo se enfoca en la experiencia de usuario (UX) y en las funcionalidades clave, sirviendo como base para un desarrollo futuro más completo.

---

## 🎯 Objetivos

* Centralizar la gestión de citas en una sola plataforma
* Reducir errores de agendamiento
* Facilitar la visualización de disponibilidad
* Optimizar el tiempo tanto del administrador como del cliente

---

## 🚀 Funcionalidades principales

* 📅 Creación, edición y cancelación de citas
* 👤 Gestión básica de usuarios (administrador / cliente)
* ⏰ Visualización de disponibilidad por fecha y hora
* 🔔 Recordatorios de citas (simulados en el prototipo)
* 📊 Vista general de citas programadas

---

## 🧩 Alcance del prototipo

Este proyecto es **solo un prototipo**, por lo que:

* No incluye pasarela de pagos
* No cuenta con autenticación avanzada
* Los datos pueden ser simulados o almacenados de forma local

Su propósito es demostrar la idea, el flujo y la estructura de la aplicación.

---

## 🛠️ Tecnologías utilizadas

Este prototipo fue desarrollado utilizando una estructura simple y funcional:

* Backend: **PHP**
* Base de datos: **MySQL**
* Archivos principales:

  * `index.php`: interfaz principal y lógica de presentación
  * `api.php`: manejo de peticiones y comunicación con la base de datos

No se utilizan frameworks externos, lo que facilita la comprensión del flujo básico de la aplicación.
